# 🏠 House Price Prediction Using Machine Learning
## Project Overview
House Price Prediction is a machine learning project that uses Linear Regression to estimate house prices based on property details.

## Objective
To develop an interactive application that predicts estimated house prices using machine learning.

## Input
- Area (square feet)
- Number of bedrooms
- Number of bathrooms
- Age of the house (years)

## Output
- Estimated house price in lakhs (₹)
